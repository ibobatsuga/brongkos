# Motion presets
- `kinetic-type`: bold Inter or approved font, navy/white canvas with orange emphasis, 250–400ms ease-out, no strobe.
- `liquid-glass`: secondary ONLY, retain clean Instadeck UI feeling; never replace authentic dashboard with a fake translucent design.
- `saas-demo`: approved screenshot panning/zooming, readable labels, no UI redrawing or fabricated notifications.
- `pop-bold`: restrained campaign variant using official orange/navy/white, not unrelated lime/purple.
- `editorial`: content stories and media owners; typography proposals need approval.
- `hybrid-default`: VO-led kinetic hook → real UI walkthrough → concise recap → intact logo CTA.

Implement these as local animation presets after inspecting the installed HyperFrames skills documentation. `templates/scene-starter.html` supplies an offline storyboard preview, not a full HyperFrames render implementation.
